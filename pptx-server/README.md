# 키즈밀 식단표 PPTX 서버 — Step 2-A (로컬 8개 샘플)

CK 공통 식단 1벌을 **원(branch)별 PPTX 식단표**로 자동 생성하는 Python 모듈.
이 단계는 **로컬 단독 검증**만 다룬다. Storage/Next.js 연결은 다음 단계(49개 확대).

> ★ 대원칙: **디자이너 템플릿 100% 유지.** 셀의 `run.text` 만 교체하며
> 폰트/색상/레이아웃/표 구조는 일절 건드리지 않는다.
> 알러지 원문자(①~⑲)는 빨간색 별도 run 으로 분리돼 있어, 메뉴명(검정)+
> 알러지(빨강) run 구조를 그대로 살려 색을 유지한다. `cell.text = ...` 금지.

### 1. 의존성 설치
```
pip install -r requirements.txt
```

### 2. templates/ 에 8개 PPTX 넣기 (파일명 정확히)
| 원 | 타입 | 파일명 |
|----|------|--------|
| 목동E   | A       | `(목동ECC).pptx` |
| 수지P   | B       | `(수지POLY).pptx` |
| 강동E   | C       | `(강동ECC).pptx` |
| 송파알티 | D       | `(알티오라 송파).pptx` |
| 목동P   | E       | `(목동POLY).pptx` |
| 일산P   | F       | `(일산POLY).pptx` |
| 엘란    | G       | `(엘란어학원).pptx` |
| 송파E   | 송파E   | `(송파ECC).pptx` |

### 3. 실행
```
python local_test.py
```
- 먼저 `bracket_parser` 단위테스트가 돌고,
- templates/ 에 있는 PPTX 만 생성하여 `output/<원명>_생성.pptx` 로 저장한다.
- 템플릿이 없는 원은 **SKIP** 으로 표시되며, 넣고 다시 실행하면 된다.

### 4. output/ 결과 확인
PowerPoint 로 열어 텍스트가 올바르게 교체됐는지, 서식(폰트/색/레이아웃)이
원본 그대로인지 확인한다.

### bracket_parser 단독 테스트
```
python bracket_parser.py
```

## 타입별 행 구조 (실측 확정)

| 타입 | 구조 |
|------|------|
| A (목동E)   | S1 10행 (중식+오전간식) |
| B (수지P/KPI) | S1 10행(중식+간식) + S2 5행(오후간식) |
| C (강동E)   | S1 15행 (중식+오전+오후, 3행1세트) |
| D (송파알티) | S1 15행 + S2 15행 (둘 다 동일 데이터) |
| E (목동P)   | S1 10행(5주차만 '오전'). **S2/S3 빈 슬라이드 — 건드리지 않음** |
| F (일산P)   | S1 국문 + S2 영문 + S3 국문오후 + S4 영문오후 (영문도 한글 유지) |
| G (엘란)    | S1+S2(알러지표기) + S3+S4(**알러지 미표기 ①~⑲ 제거**) |
| 송파E       | S1 10행 + S2(오후/저녁 교대, **저녁=돌봄간식**) |

열 구조(공통): 열0=라벨, 열1=월 … 열5=금.

## 셀 내용 형식
- **중식 셀**(줄바꿈): 밥 / 국① / 반찬1②⑤ / 반찬2 / 반찬3 / (반찬4·5) / 466Kcal(탄59단16지23)
- **간식 셀**: 메뉴명①② / 130Kcal

---

## 특수처리 10가지 (구현됨)
1. 간식 라벨 `오전`→`간식` 교체 — 수지P·수지P별관·광교P·대치P·미사알티·광교알티
   (단 일산P/목동P S1 은 원래 '간식'이라 그대로, 5주차 행은 '오전' 유지)
2. 동탄P → 오전간식 무조건 `유기농우유② / 75Kcal` 고정 (`fixed_am`)
3. KPI → 오후간식 `유기농우유`→`무항생제멸균우유` 치환 (`pm_replace`)
4. 송파E → S2 저녁행에 돌봄간식 매핑 (`care` 섹션)
5. 5주차 '해당없음' → 해당 행 전체 빈칸 (`is_skipped`)
6. 공휴일 → 해당 날짜 중식 셀 빈칸 (`is_holiday`)
7. 잉파/엘란 → 중식 셀 마지막에 후식과일 행 추가 (`add_fruit`)
8. 엘란 S3/S4(미표기) → 알러지 원문자 ①~⑲ 제거 (`strip`)
9. 목동P/일산P 영문 슬라이드 → 한글 그대로 (번역 X)
10. 목동P S2/S3(건강정보지) → 절대 건드리지 않음 (`skip`)

## 대괄호(원별 오버라이드) 표기 규칙 — `bracket_parser.py`
메뉴 셀 텍스트에 인라인으로 붙는다.

| 표기 | 의미 |
|------|------|
| `메뉴[원명-대체메뉴]` | 해당 원은 대체메뉴로 교체 |
| `메뉴[원명-메뉴명X]`  | 해당 원은 이 항목 제거(대시 뒤 X) |
| `메뉴[원명X]`         | 해당 원은 이 항목 제거(대시 없음) |
| `[후식과일]`          | 후식과일 추가 플래그 |
| `[원명1,원명2-대체]`  | 복수 원 동시 적용 |
| `[P-대체]` 등         | 브랜드코드 전체 확장 (**동탄P 제외**) |

매칭 안 되는 원은 대괄호를 제거한 기본메뉴를 그대로 사용한다.
